# Prism Color Themes

**English** · [中文](#zh)

**Prism Color Themes** is a VS Code theme collection. The first drop ports **12 themes** (6 families × dark/light) 1:1 from the built-in themes of the [T3 Code](https://t3.dev/) desktop app, plus a **status-bar quick switcher** and a T3-style color scheme picker. More non-T3 theme families will be added over time.

## Theme Families

| Family | Dark (editor bg) | Light (editor bg) | Notes |
|---|---|---|---|
| **T3 Ocean** | `#17212b` | `#f5f7f8` | Deep navy |
| **T3 Grove** | `#1b2821` | `#f3f7f4` | Moss green |
| **T3 Ember** | `#291e1a` | `#f9f7f5` | Warm brown |
| **T3 Iris** | `#1d1929` | `#f8f7f9` | Violet |
| **T3 Chat** | `#1f1a24` | `#fdf7fd` | T3 default |
| **T3 Material** | `#0F111A` | `#FAFAFA` | Original Material Ocean / Lighter bundled in T3 |

- The first 5 families map the **T3 UI palettes** (all 61 OKLCH semantic keys converted per-key, in dark and light variants) onto the workbench look — sidebars, controls, terminal — while syntax highlighting follows the Material token rules bundled in T3 (82 rules).
- The 6th family is the original Material theme embedded in T3's code viewer, kept as-is (`#0F111A` monochrome chrome).

## Quick Switching

- A button like `◐ Ocean Dark` shows up in the **bottom-right** of the status bar. Click it to open a picker with all 12 themes (grouped by family, labeled dark/light, current one checked).
- The command **`Prism Themes: Quick Switch Theme`** does the same from the command palette.
- Switching is instant, and the status-bar label stays in sync no matter how the theme is changed.

## Install

Search **Prism Color Themes** in the VS Code Marketplace, or:

```bash
code --install-extension blueskeys.prism-themes
```

This repo is the source. Open the `prism-themes/` folder in VS Code and press `F5` to preview, or:

```bash
cd prism-themes
npx @vscode/vsce package
code --install-extension prism-themes-1.0.4.vsix
```

You can also copy the `prism-themes/` folder directly into `~/.vscode/extensions/prism-themes-1.0.4/`.

## Build & Regeneration

The theme JSONs are generated by scripts from T3 Code's real theme definitions (no eyeballed colors). Palettes can be extracted from a local install (`server.asar`) or taken directly from the MIT repo's `packages/shared/src/themePalettes.ts`:

```bash
python tools/extract_all.py       # extract 5 palettes + 2 Material bases → tools/data/
python tools/generate_themes.py   # generate the 12 themes/*.json per the mapping
```

See `ocean-vscode-mapping.md` in the repo root for the full key mapping.

# Prism Color Themes（中文）

**Prism Color Themes** 是一个 VS Code 主题合集。第一批收录从 [T3 Code](https://t3.dev/) 桌面应用内置主题 1:1 提取移植的 **12 套主题**（6 族 × 深/浅），附带**右下角状态栏快速切换**与 T3 风格的 Color Scheme 选择器。后续将陆续加入更多非 T3 来源的主题家族。

## 主题清单

| 族 | 深色（editor 背景） | 浅色（editor 背景） | 说明 |
|---|---|---|---|
| **T3 Ocean** | `#17212b` | `#f5f7f8` | 深海军蓝 |
| **T3 Grove** | `#1b2821` | `#f3f7f4` | 苔绿 |
| **T3 Ember** | `#291e1a` | `#f9f7f5` | 暖褐 |
| **T3 Iris** | `#1d1929` | `#f8f7f9` | 紫罗兰 |
| **T3 Chat** | `#1f1a24` | `#fdf7fd` | T3 默认 |
| **T3 Material** | `#0F111A` | `#FAFAFA` | T3 内嵌的原版 Material Ocean / Lighter |

- 前 5 族 = **T3 界面调色板**（61 个 OKLCH 语义键逐键转换，深浅两版）负责 workbench 外观 + 侧栏/控件/终端层次，语法高亮用 T3 内嵌的 Material token 规则（82 条）。
- 第 6 族 = T3 代码查看器内嵌的原版 Material 主题，原样保留（`#0F111A` 单色 chrome）。

## 快速切换

- 状态栏**右下角**会出现 `◐ Ocean Dark` 按钮，点击弹出 12 套主题选择器（按族分组、标注深浅、当前项打勾）。
- 命令面板执行 **`Prism Themes: Quick Switch Theme`** 效果相同。
- 切换即时生效；状态栏标签会跟随任何途径的主题变更自动同步。

## 安装

在 VS Code 扩展市场搜索 **Prism Color Themes** 安装，或：

```bash
code --install-extension blueskeys.prism-themes
```

本仓库为源码。用 VS Code 打开 `prism-themes/` 目录后 `F5` 调试预览，或：

## 生成与再构建

主题 JSON 由脚本从 T3 Code 的真实主题定义生成（不是目测取色）。调色板可从本机安装包（`server.asar`）提取，也可直接取自 MIT 开源仓库的 `packages/shared/src/themePalettes.ts`：

```bash

python tools/generate_themes.py   # 按映射表生成 12 套 themes/*.json
```

键位映射的完整说明见仓库根目录 `ocean-vscode-mapping.md`。
