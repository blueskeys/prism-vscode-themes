# prism-vscode-themes

**Prism Themes** — a VS Code theme collection.

First drop: 12 themes (6 families × light/dark) ported 1:1 from the [T3 Code](https://t3.dev/) desktop app, with a status-bar quick switcher and a T3-style color-scheme picker.

➡️ See [prism-themes/README.md](prism-themes/README.md) for the full theme list, install instructions, and build steps.
